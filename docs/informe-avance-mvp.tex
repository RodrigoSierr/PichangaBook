\section{Resumen del Avance del MVP}

En este documento presentamos las evidencias de avance del Producto Mínimo Viable (MVP) de \textbf{PichangaBook Arequipa} (repositorio \texttt{github.com/RodrigoSierr/PichangaBook}). El proyecto resuelve tres problemas al alquilar canchas sintéticas en Arequipa: las reservas duplicadas entre recepción y WhatsApp, la dificultad de cobrar la cuota a cada amigo del partido y la falta de suplentes de último minuto. Hasta la fecha hemos implementado el esquema de base de datos en \textbf{PostgreSQL}, el servidor backend en \textbf{NestJS con Socket.io} y las interfaces de usuario en \textbf{HTML5/Tailwind CSS} (panel web de dueños) y \textbf{Flutter/Dart} (aplicación móvil para jugadores).
